# Options Bullish Scanner 🎯

منصة فلترة عقود الخيارات للسوق الأمريكي - تبحث عن العقود ذات إشارات الصعود القوية.

## ⚠️ تحذير مهم

هذه **أداة تحليل فقط**، ما هي توصية استثمارية. عقود الخيارات عالية المخاطر وممكن تخسر كامل راس المال.
استخدمها كأداة مساعدة للبحث، وتأكد بنفسك قبل أي قرار.

## الميزات

- **فلترة شاملة**: Unusual Volume, Momentum, IV, السيولة
- **Bullish Score 0-100**: تقييم تلقائي لكل عقد
- **إشارات متعددة**: كل عقد يطلع بتفاصيل ليش اختير
- **Calls / Puts**: فلترة حسب النوع
- **فلاتر قابلة للتعديل**: الحجم، OI، المدة، الخ
- **+40 سهم مدمج**: يمسح الأسهم الأكثر شعبية تلقائياً (أو خصص أسهمك)

## كيف تشغلها

### 1) Backend (Python)

```bash
cd backend
pip install -r requirements.txt
python3 main.py
```

السيرفر راح يشتغل على: `http://localhost:8000`
صفحة API docs: `http://localhost:8000/docs`

### 2) Frontend

افتح ملف `frontend/index.html` في المتصفح. خلاص.

## كيف يحسب الـ Bullish Score

يعتمد على 6 عوامل:

| العامل | النقاط | الوصف |
|-------|--------|------|
| Unusual Volume (5x+) | +30 | حجم تداول ضخم جداً مقارنة بـ OI |
| Unusual Volume (3x+) | +20 | حجم غير طبيعي |
| Momentum (+2%) | +20 | السهم صاعد بقوة |
| OTM قريب (<3%) | +15 | أفضل نسبة مخاطرة/مكافأة |
| IV معقول (30-80%) | +10 | مو غالي ولا رخيص جداً |
| سيولة ممتازة (spread<5%) | +10 | سهل الدخول والخروج |
| OI شائع (1000+) | +5 | عقد مشهور |

**60+ = إشارة قوية 🔥**
**40-59 = إشارة متوسطة ⚡**
**<40 = ضعيفة**

## مصدر البيانات

Yahoo Finance (مجاني) - بيانات مؤجلة ~15 دقيقة.
للبيانات الفورية (real-time) لازم تستخدم Polygon.io أو Tradier (مدفوع).

## التخصيص

- **زيادة الأسهم**: عدّل `DEFAULT_TICKERS` في `backend/main.py`
- **تغيير منطق الـ Score**: دالة `calculate_bullish_score` في `main.py`
- **تغيير الـ API**: غير `const API` في `frontend/index.html`
